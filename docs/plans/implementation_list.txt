    1. BatchImportReport dataclass (imported, skipped, errors)
    2. parse_review_list(file_path): parse paper_review_list.txt format.
       Paper blocks delimited by "--- Paper N/M ---" headers, ending at
       80-char dash separator. Extract Title: line value (strip after colon).
       Decision line: [X] ACCEPT means verdict="accept", [X] REJECT means
       verdict="reject". Skip papers with no [X] mark.
       Notes: multiline text until separator. May contain "Score: N" for
       explicit score (N in 1-5); otherwise derive: accept=4, reject=1, skip=3.
       Notes text (minus Score: prefix) becomes rationale.
       Return list of {"title": str, "verdict": str, "notes": str, "score": int}.
    3. import_reviews(conn, file_path, reviewer): call parse_review_list(), for each
       entry look up Source by title:
       SELECT id FROM nodes WHERE kind = 'Source' AND json_extract(attrs, '$.title') = ?
       If no Source found: add {"title": ..., "reason": "Source not found by title"} to errors.
       If Source found: call review_paper(conn, source_id, reviewer, score, verdict, rationale).
       Catch ValueError (duplicate review) -> increment skipped (idempotent).
       Return BatchImportReport(imported, skipped, errors).
    4. export_review_list(conn, output_path): query research-type Sources:
       SELECT id, attrs FROM nodes WHERE kind = 'Source' AND json_extract(attrs, '$.source_type')
       IN ('paper','preprint','conference-paper','conference-proceedings')
       ORDER BY json_extract(attrs, '$.published_date') DESC.
       For each Source, check reviewed-by edges:
       SELECT n.attrs FROM edges e JOIN nodes n ON e.target_id = n.id
       WHERE e.kind = 'reviewed-by' AND e.source_id = ? AND n.kind = 'HumanReview' LIMIT 1.
       Write in paper_review_list.txt format: reviewed papers get [X] ACCEPT/REJECT
       with Score: N and rationale in Notes. Unreviewed papers get empty checkboxes.
    5. CLI main() with argparse subparsers:
       "import --db --file --reviewer" calls import_reviews, prints JSON report.
       "export --db --output" calls export_review_list, prints confirmation.
